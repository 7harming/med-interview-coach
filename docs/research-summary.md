# 研究摘要：台灣醫學系二階面試在看什麼

研究日期：2026-11-11。這份摘要服務於本題庫與教練尺規，**不是**官方題庫，也不是各校招生委員會的說明。題幹每年更換；形式以當年度大學招聯會校系分則與學系公告為準。

整理時讀過的材料包括：115 學年度校系分則、中山醫選才尺規、中國醫 115 面試注意事項、教授與院長的公開訪談、PTT／Dcard／個人站的考生第一手回憶，以及升學機構的轉述。升學機構文字只用來對照形式與題型，**沒有**把補習班講義原文放進這個公開題庫。

## 近十年公開回憶的題型比例

2016–2026 年間，能對上來源的醫學系提問約 301 則（一則是考生需要單獨回答的一個問題；改了情境的追問另計）。分類是整理時的主要歸類，很多題其實跨類。

| 類別 | 則數 | 約略比例 |
| --- | ---: | ---: |
| 時事與醫療政策 | 74 | 25% |
| 學習歷程／書審延伸 | 36 | 12% |
| 醫學倫理 | 35 | 12% |
| 自我認識 | 33 | 11% |
| 動機與志向 | 32 | 11% |
| 情境／溝通 | 31 | 10% |
| 邏輯思辨／圖表 | 29 | 10% |
| 其他（英文、詩文、觀察、特定知識） | 22 | 7% |
| 團隊合作 | 9 | 3% |

「其他」沒有獨立做成題庫類別：英文朗讀與詩文不適合這個純中文、無圖的 MVP。團隊合作在原始歸類裡很少，是因為很多合作衝突被記成情境題（好友錄取順位、活動總召、組長面對不做事的組員）。本題庫仍把團隊合作獨立出來，題數略高於 3%，讓學生練得到；時事題仍是最大類。72 題的實際分布見題庫，並由測試鎖住。

各校出題習慣，濃縮後是：

- **臺大**指定題很少直接問「為什麼讀醫」，而是用圖表、公平與可近性看你能不能讀資料。個人題時間短。
- **陽明／陽明交大**同時看個人（含備審追問）與開放的團體討論。
- **成大**站與站差很多：壓力、推理、應變、備審都有。簡章說要看習醫特質；壓力關仍可能丟出高中生不會的名詞，考生回憶考官看的是被挑戰時的態度。
- **北醫**個面追問人生選擇，團面常見倫理兩難。
- **高醫**常把時事和團隊情境放在同一關。
- **中國醫**題目大量要求換位。109 學年度考生寫考官幾乎不追問，自己要把時間講完；115 公告已無團體面試。
- **中山醫**個面像深聊備審，PBL 進入臨床倫理或健康不平等。
- **長庚**有過公平看診、權勢關說這類溝通站；個人管線則高度追問自介。
- **馬偕**關數多，弱勢、誠信、衝突、時事都出現。考生轉述系上強調「有溫度」，這是轉述，不是簡章原文。
- **慈濟**官方要世界公民、同理、批判思考、語文與醫學適性；不同年度題型擺盪很大。
- **輔大、義守**是多站，溝通、衛教、倫理、抗壓都看得到。義守公費與離島服務的連結較清楚。

## 教授公開談過的好回答與弱回答

以下只保留有姓名或有官方文件的說法，加上與這些說法一致、且在多份考生回憶裡重複出現的模式。

**動機要經得起追問。** 吳瑞裕認為「想照顧生病的家人」太狹隘，競賽獎項也說明不了為什麼選醫學系；他要看你喜不喜歡人，以及有沒有想過這份工作的辛苦。<https://ioh.tw/articles/ioharticles-%E5%A4%A7%E5%AD%B8%E5%82%99%E5%AF%A9-%E9%86%AB%E5%AD%B8%E7%B3%BB%E9%9D%A2%E8%A9%A6>

**不要隱惡揚善。** 同一篇訪談裡，他說老師想看缺點和你自己的想法，而不是五花八門的活動清單。活動要用得上，才顯得出特質。

**沒有標準講稿。** 李惠娥說口試不預設正解，看的是反應與邏輯；為了時數去志工，老師只當參考。沒有華麗社團的學生，若把真實生活講清楚，仍可能得到高評價。<https://ioh.tw/articles/%E5%A4%A7%E5%AD%B8%E6%95%99%E6%8E%88%E7%9C%8B%E9%9D%A2%E8%A9%A6_160402>

**地位與收入不是動機。** 陳定信 2007 年受訪：只想賺錢、對人沒興趣，不要選醫科。<https://news.ltn.com.tw/news/life/paper/125253> 劉克明批評把讀醫廣告成「吃香喝辣」，並指出台灣學生常見的習醫動機是雙親期望、助人與個人興趣，面談幾乎一定會問到動機。<https://enews2.kmu.edu.tw/index.php/Enews337_%E5%85%A5%E5%AD%B8%E6%8B%9B%E7%94%9F%E9%9D%A2%E8%AB%87%E8%AB%87%E4%BB%80%E9%BA%BC%3F_%281%29>

**套語沒有鑑別度。** IOH 編輯整理點名「受史懷哲影響」「奶奶中風看見體系不足」是司空見慣的說法。<https://ioh.tw/articles/%E5%A4%A7%E5%AD%B8%E9%9D%A2%E8%A9%A6_160404>

和上述來源一致、在考古題裡反覆出現的弱回答：

- 倫理題立刻選邊，沒有問誰有權決定、誰承擔後果。
- 政策題只剩憤怒，沒有在限制下做得到的下一步。
- 志工與服務只報時數、頭銜、公里數。
- 備審寫了，過程、數字、自己的角色卻答不出來。
- 不會的時候用背下來的原則填滿，或改口討好。

本題庫每一題的 `weakTraps` 與 `strongAnswer` 都從這些模式改寫，不提供可背的標準答案。

## 題庫怎麼用這些發現

`data/questions.json` 的 72 題是**另寫的練習題**。每一題用 `inspiredBy` 標出它對照的學校、學年度與公開來源網址，方便查證題型，而不是宣稱該年原題就是這一段文字。

形式欄位只有兩種：

- `traditional`：多對一裡的一個提問，沒有閱讀倒數。
- `mmi`：有閱讀時間與作答時間。時間對照考生回憶與中國醫 115 公告的量級（讀題約 1–2 分鐘、作答約 5–7 分鐘），不是某一關的官方計時。

沒有收進 MVP 的題型：英文朗讀與翻譯、需要圖片或紙筆的圖表題（改寫成文字描述的推理題有收）、生物化學實作、團體演戲。這些在真實面試裡存在，這個版本做不到。

## 使用限制

1. 考生回憶會記錯。同一年兩位考生的題幹可能不同，摘要不把它們合成「官方題」。
2. 補習班講義會改寫。能與第一手對上的題型較可信；對不上的只當作題型存在過。
3. 形式會改。中國醫 115 已寫明無團體面試；長庚並非每年都是 MMI。
4. 考生對「這所學校要什麼樣的人」的感想，沒有被寫成官方招生理念。
5. 國防醫學院在這次整理裡沒有找到可核對的逐關題幹，題庫不偽造該校題目。
