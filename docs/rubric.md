# 練習用評分規準

這份尺規給模擬面試的教練使用，也給學生對照。它**不是**任何一所醫學系的官方給分表，也不能預測錄取。

115 學年度各校簡章對口試的寫法並不一致。臺北醫學大學、中國醫藥大學、中山醫學大學、輔仁大學、慈濟大學、長庚大學、義守大學寫得較具體；臺大、陽明交大、成大、高醫、馬偕多半寫培育目標或只說用來了解習醫特質。下面七個構面是把這些公開項目收斂成練習時打得開、也聽得見的維度。機器可讀版本在 `data/rubric.json`。

分數是 1 到 5。某構面在這次對話裡根本沒被談到時，教練應標成「資料不足」，而不是用中間分充數。證據必須是學生逐字稿裡的原句。

總提醒：面試沒有預設的標準答案。高雄醫學大學牙醫學系教授李惠娥談口試時說，教授要看的是臨場反應與思考邏輯，而不是一個事先寫好的正解（[IOH，2016](https://ioh.tw/articles/%E5%A4%A7%E5%AD%B8%E6%95%99%E6%8E%88%E7%9C%8B%E9%9D%A2%E8%A9%A6_160402)）。這句話常被醫學系準備文章引用；本尺規沿用這個前提。

## 動機真實度與具體性

官方錨點：北醫「醫學適性、學習態度」；高醫教育目標裡的服務熱忱；陽明交大「仁心仁術、終身學習」；高醫名譽教授劉克明寫，招生面談最常被問的就是習醫動機（[高醫 e-News](https://enews2.kmu.edu.tw/index.php/Enews337_%E5%85%A5%E5%AD%B8%E6%8B%9B%E7%94%9F%E9%9D%A2%E8%AB%87%E8%AB%87%E4%BB%80%E9%BA%BC%3F_%281%29)）。

| 分數 | 聽起來像 |
| --- | --- |
| 1 | 只有「想救人」「想幫助人」，或把讀醫說成地位、收入、家人面子。 |
| 2 | 有個人故事，但仍是單一事件或家人期望的複述，說不出這份工作平常有多累。 |
| 3 | 能區分醫師和其他助人工作，也連得上一段經驗；對辛苦的理解還很概括。 |
| 4 | 用具體場景說明為什麼是醫學系，並承認工時、責任與不確定。追問時補得下去。 |
| 5 | 動機、經驗、對職業限制的理解互相咬合；說得出什麼新經驗會讓自己重新考慮。 |

較好的方向：北醫副教授吳瑞裕說，親戚生病所以要照顧自己人「太小、太狹隘」；核心是喜不喜歡人，而不是社會地位或收入這張標籤（[IOH，2017](https://ioh.tw/articles/ioharticles-%E5%A4%A7%E5%AD%B8%E5%82%99%E5%AF%A9-%E9%86%AB%E5%AD%B8%E7%B3%BB%E9%9D%A2%E8%A9%A6)）。2007 年臺大醫學院院長陳定信受訪時也說，只想賺錢、對人沒興趣的人不要選醫科（[自由時報](https://news.ltn.com.tw/news/life/paper/125253)）。

較弱的方向：「受史懷哲影響」「奶奶中風讓我看到體系不足」這類被 IOH 點名的套語（[IOH，2016](https://ioh.tw/articles/%E5%A4%A7%E5%AD%B8%E9%9D%A2%E8%A9%A6_160404)）；或完全沒想過醫師工作很辛苦（吳瑞裕）。

具體對照：不要只說「我想幫助人」。要說出哪一段經驗讓你決定用當醫師而不是當老師、社工或藥師來做這件事，並講出你知道的一種日常辛苦。

## 邏輯結構

官方錨點：北醫「邏輯思考」；中山醫「科學知識與邏輯推理」；輔大「邏輯思辨、解決問題」；長庚「思辨」；義守「思考」。臺大近年指定題大量用圖表，看的是能不能讀資料再下判斷。

| 分數 | 聽起來像 |
| --- | --- |
| 1 | 先下結論且沒有理由，或把沒看懂的圖和新聞直接當成事實。 |
| 2 | 有立場，理由只有一句，或把相關說成因。 |
| 3 | 聽得出現象、可能原因、自己的判斷。中間偶有跳躍。 |
| 4 | 分得開已知、推測、還缺的資料；提出的作法接得上前面的原因。 |
| 5 | 在限制下比較方案，說明取捨；資料不夠就明講。 |

較好的方向：先描述現象與原因，再提出在現實限制下可做的下一步。臺大 113 學年度「偏鄉特別有效但當地負擔不起的新藥」這類題，弱的答法是立刻說藥廠應免費，或只罵制度；較穩的答法是先承認研發、病人、其他等待用藥的人、給付制度各自的限制，再講一個可討論的作法，並說明什麼新資訊會讓你改決定。

較弱的方向：批評很完整，但沒有任何做得到的下一步。

## 多元觀點／利害關係人

官方錨點：中國醫「獨立思考、同理心」；慈濟「世界公民、批判思考」。考古題本身常要求「如果你是 A、如果你是 B」。

| 分數 | 聽起來像 |
| --- | --- |
| 1 | 只站在最好答的那一方，其他人被說成不對。 |
| 2 | 提到第二個人，但只為了馬上駁回。 |
| 3 | 說得出至少兩方在意什麼；判斷偏快，少談資源限制。 |
| 4 | 病人、家屬、現場人員、制度的代價都被點到，也說得出反方最強的理由。 |
| 5 | 說得出誰沒有發言權、誰在承擔後果，以及什麼新資訊會讓你改邊。 |

較好的方向：中山醫 114 學年度高齡病人是否插鼻胃管、洗腎，家屬意見不同。弱的答法是直接選邊，或沒有先問本人能不能做決定。較穩的答法是：意識清楚時本人是主要決定者；主要照顧者與不住在一起的家屬都要被聽到，但不能取代本人；再分開談負擔、生活品質與若意識不清楚時的程序。

較弱的方向：倫理題開口就是「我會尊重病人」，沒有看見家屬與團隊（TBD Studio 對常見錯誤的整理，[2026](https://tbd-edu.com/pages/resources/medical-interview.html)）。

## 人文關懷與同理

官方錨點：中國醫、中山醫、高醫、輔大、慈濟、北醫都把人文、關懷、同理或尊重生命寫進面試或教育目標。中山醫選才說明把「對社會的關懷」對上專業素養與病患照護（[招生處 PDF](https://recruit.csmu.edu.tw/var/file/19/1019/img/1987/705792609.pdf)）。

| 分數 | 聽起來像 |
| --- | --- |
| 1 | 人被當成題目、時數或阻礙。 |
| 2 | 有安慰的意願，但說不出對方在怕什麼。 |
| 3 | 描述得出處境與情緒，關懷停在態度。 |
| 4 | 同理連到一句話怎麼講、時間怎麼留、資源找誰；不把自我犧牲當成唯一的善。 |
| 5 | 同時看見公平、病人安全與自己的限度，不浪漫化受苦。 |

較好的方向：高醫 114 學年度「災後連續工作超過 24 小時且已失誤，留下或休息」。弱的答法是把休息說成沒醫德，或只想離開、不處理眼前的病人安全。較穩的答法是把疲勞和病人安全看成同一件事，談交接、求救與輪替。這也呼應吳瑞裕說的：要想過將來怎麼面對這份工作的辛苦。

較弱的方向：志工只報時數和頭銜。李惠娥批評為了時數去當志工；她要看的是責任感與有沒有把關懷做成行動。

## 溝通表達

官方錨點：115 學年度幾乎所有有列出項目的學校都寫了語言、溝通或表達。長庚另寫應對禮儀。臺大備註要求口語表達、人際互動與抗壓。

| 分數 | 聽起來像 |
| --- | --- |
| 1 | 聽不出在答哪一問；背稿腔很重。 |
| 2 | 有答，但離題、過長，或堆沒解釋的名詞。 |
| 3 | 問什麼答什麼，重點不夠靠前。 |
| 4 | 先給結構再展開；被打斷時接得住，不把稿再念一次。 |
| 5 | 用對方聽得懂的話講複雜的事；承認不懂，語氣穩。 |

較好的方向：輔大 110 學年度偏鄉長者衛教，對象平均 75 歲、小學程度。重點不是複誦口號，而是步驟短、可以示範、並確認對方做得出來。

較弱的方向：自我介紹或回答聽起來在背稿。儒林講義與長庚錄取生都提過這件事；IOH 也說全照面試守則做，只會顯得沒有思考。本產品的教練可以指出「像背稿」，但不會提供一篇讓學生再背的講稿。

## 自我反思

官方錨點：吳瑞裕明確說書面資料常見的問題是隱惡揚善，老師想看缺點和你怎麼想；活動要能顯出特質，奧林匹亞獎項說明不了為什麼選醫學系。中山醫簡章希望學習歷程反思包含事實、感受、發現、對未來的影響。

| 分數 | 聽起來像 |
| --- | --- |
| 1 | 只有成功清單；或說自己沒有挫折。 |
| 2 | 有挫折，收尾却是「所以我更努力了」，無法再追問。 |
| 3 | 有一件具體的事、當時的感受、一個改變。 |
| 4 | 說得出盲點、後來怎麼核對，以及這個習慣在壓力下還會不會失靈。 |
| 5 | 反思改得動行為；備審裡的細節經得起追問，也敢說哪裡寫太滿。 |

較好的方向：李惠娥回憶一位沒有漂亮社團、每天幫忙家裡送菜的學生，因為講得具體、態度正向而得到高評價。沒有醫院志工不等於這個構面是零。

較弱的方向：成大錄取生彙整裡，教授會追問備審細節，也會直接問哪裡有誇大。寫進去卻答不出過程，比少寫更傷。

## 應變與抗壓

官方錨點：輔大「抗壓性」；長庚、義守「反應」；臺大備註「抗壓」。成大簡章寫面試是為了了解習醫特質，考生回憶裡仍會遇到壓力關。

| 分數 | 聽起來像 |
| --- | --- |
| 1 | 一被追問就改口討好、僵住，或不懂裝懂。 |
| 2 | 會說不會，但拒絕再想；或立刻情緒化。 |
| 3 | 承認不知道，並試著用題目已給的資訊推理。 |
| 4 | 把反駁當成新條件，維持禮貌與速度。 |
| 5 | 在不確定裡仍排得出優先順序，也說得出自己的壓力訊號與求助方式。 |

較好的方向：不會並不可恥，不懂裝懂才是問題。被問到不會的專有名詞時，先說不會，再用題幹裡看得到的條件繼續想。

較弱的方向：用背下來的倫理口訣蓋過沉默，或宣稱自己剛剛講的就是標準答案。

## 教練使用這份尺規時的硬規則

1. 每個分數旁邊都要有學生自己說過的話。沒有原句就不要給分。
2. 不要把學生沒說的動機、志工或家庭故事補進去。
3. 弱點要對到研究裡反覆出現的陷阱：空泛救人、倫理題秒選邊、只報時數、只罵制度、背稿、不懂裝懂、備審經不起追問。
4. 「更好的結構」只示範順序，例如「先兩方處境，再你的判斷，再一個會讓你改決定的條件」。不要寫成可背的全文。
5. 語速、語助詞、長停頓用逐字稿與時間戳計算，不要憑空形容學生「聽起來很緊張」。
6. 報告必須寫明：這是練習回饋，不是錄取預測。
